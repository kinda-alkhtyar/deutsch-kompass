# Deutsch Kompass — Final Platform Edition

Responsive static language-learning platform for A1–B1.

## Highlights
- 1500 Wörter & Wendungen
- Every vocabulary entry shows A1/A2/B1 examples on the SAME page
- Arabic meaning and Arabic learner explanation/translation for every example block
- Daily-life vocabulary by topic
- Grammar A1–B1
- Pronunciation & speaking workflow
- Flashcards / dictation / Artikel / sentence order / Mega Test
- Bildbeschreibung with an actual image
- E-Mail / Sprechen / Lesen / Österreich & Werte exam center
- Separate A1 / A2 / B1 final exam entry points
- Smart review and saved/hard/known words
- Responsive for phone, tablet, and desktop
- PWA-friendly and GitHub Pages friendly
- No npm/build step required

## Run
Open the folder in VS Code and run `index.html` with Live Server.

## Publish on GitHub Pages
Settings → Pages → Deploy from a branch → main → /(root)
